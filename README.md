# רשימת אורחים אדירים — כלי שבועי

אפליקציית Next.js לניהול רשימת המבקרים השבועית של צ'פטר BNI אדירים. ייבוא (הדבקה / CSV /
אקסל), תיקון בטבלת ביקורת, שמירה לדאטהבייס, ותצוגה מעוצבת עם דירוג מזמינים, מיון, ווטסאפ
וייצוא לאקסל.

## הרצה מקומית

```bash
npm install
npm run seed     # טוען את שבוע 23/07/2026 לדוגמה (אופציונלי)
npm run dev      # http://localhost:3000
```

הדאטהבייס המקומי הוא קובץ `data/local.db` (libSQL), נוצר אוטומטית. לא נכנס לגיט.

## שימוש שבועי

0. היכנס דרך **`/login`** עם היוזר והסיסמה (משתני הסביבה `ADMIN_USER` ו-`ADMIN_PASSWORD`).
   בלי כניסה הדף לצפייה בלבד, ואין כפתור עריכה.
1. לחץ **עדכן רשימה**.
2. הדבק טקסט, או ייבא CSV / אקסל. השורות נכנסות לטבלת ביקורת.
3. תקן כל שדה: שם, חברה, מזמין, טלפון, סוג (אורח / ממלא מקום / מבקר / מועמד), מין, וסימון **BNI**.
   > אימות חברות BNI נעשה מחוץ לעמוד (Playwright, ראה `SKILL.md`). כאן רק מסמנים את התוצאה.
4. קבע את **תאריך המפגש** ולחץ **שמור ופרסם**. שמירה על תאריך קיים דורסת את אותו שבוע.

## פריסה ל-GitHub + Vercel

הקובץ `data/local.db` לא עולה לגיט, אז בענן צריך דאטהבייס מנוהל. הכי פשוט — [Turso](https://turso.tech)
(דיאלקט SQLite, תואם לקוד כמו שהוא):

1. צור דאטהבייס ב-Turso וקח `Database URL` ו-`Auth Token`.
2. ב-Vercel → Project Settings → Environment Variables:
   - `DATABASE_URL` = `libsql://<db>.turso.io`
   - `DATABASE_AUTH_TOKEN` = הטוקן
   - `ADMIN_USER` = היוזר שלך (אימייל)
   - `ADMIN_PASSWORD` = הסיסמה שלך (בלי שניהם — העריכה נעולה)
3. פרוס. העמוד עולה במצב ריק; הייבוא הראשון יוצר את השבוע הראשון.
4. לטעינת שבוע הדוגמה מול הדאטהבייס המרוחק: הרץ `npm run seed` עם אותם משתני סביבה.

רוצה Postgres (Neon / Vercel Postgres) במקום? זו החלפת דרייבר ב-`lib/db/index.ts` ועדכון
הדיאלקט ב-`lib/db/schema.ts`; שאר הקוד עובר ב-`lib/repo.ts` בלי שינוי.

## מבנה

- `app/` — עמודים ו-API (`/api/weeks`, `/api/weeks/current`).
- `components/` — לוח התצוגה, פאנל הייבוא, רקע וקונפטי.
- `lib/` — טיפוסים, פרסור, סיווג, טלפון, תאריכים, גישת דאטהבייס.
- `data/seed.ts` — נתוני שבוע לדוגמה.
- `SKILL.md`, `references/` — אימות BNI אופליין (Playwright). לא חלק מזמן הריצה של האפליקציה.
